# VIEW POINT FIT — 7-minute judging guide

Open `/demo` directly. No account is required. Use “Reset demo” to clear the demo investigation state and reset sample values. This never resets a real account. There are no fake completion buttons or fabricated live API responses.

| Time | What to show |
| --- | --- |
| 0:00–0:40 | The problem: people see isolated numbers but struggle to understand daily habits. |
| 0:40–1:10 | UAE relevance: discuss everyday routines, desk work and sustainable movement. Avoid unsupported statistics or medical claims. |
| 1:10–1:45 | My Fit: the real 3D Your View avatar. Change sample steps and sleep to demonstrate the shared VIEW scoring engine. Say “sample day, non-clinical wellness score.” A confirmed account additionally shows saved check-in/history and missions. |
| 1:45–2:50 | Pose: choose an exercise, show its 3D guide, explicitly enable camera, and demonstrate a real detected repetition. Rehearse camera framing beforehand. The avatar never generates landmarks or reps. |
| 2:50–3:30 | Coach: 3D Maya, a sleep/food/movement question, and “Why this view?”. Without the server API key, explicitly call this deterministic Quick Guidance, not live AI. |
| 3:30–5:35 | Lab: select Case 001, meet Khalid, open evidence, pin clues, form a hypothesis and plan. Shared deterministic scoring drives the simulation/reveal. The public demo awards no account XP. |
| 5:35–6:05 | Show Sara’s weekly pattern case and Omar’s systems investigation. All three are playable and fictional. |
| 6:05–6:35 | Architecture: React/TanStack, Supabase/RLS/reward ledger, local MediaPipe, one server-side AI gateway, lazy Three.js characters. |
| 6:35–6:50 | Safety/privacy: preventive wellness education, no diagnosis, no raw camera video storage. |
| 6:50–7:00 | “VIEW POINT FIT. See your health from every angle.” |

For saved XP, badges, missions, meal history and refresh persistence, use a confirmed test account only after the hosted database upgrade. Demo sample inputs intentionally do not contaminate personal wellness history.

Fallbacks: camera unavailable → explain the real pipeline and show the illustrative guide; AI unavailable → labeled Quick Guidance; WebGL unavailable → illustration; database unavailable → sync error with retry. Never describe a fallback as a live integration.
